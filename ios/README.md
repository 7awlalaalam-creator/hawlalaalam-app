# تطبيق «حول العالم» على iOS

تطبيق آيفون/آيباد أصلي (SwiftUI) بنفس مميزات تطبيق أندرويد وتصميمه، ويقرأ بيانات المصحف والخطوط وجسر صفحات الموقع (`bridge.js`)
من مجلد أندرويد نفسه، فلا توجد نسختان تحتاجان مزامنة. يُبنى بالكامل على GitHub — لا تحتاج جهاز ماك.

## ما الذي فيه (مطابق لأندرويد)
- **اليوم**: الترويسة بالتاريخ الهجري والمدينة وزر الوضع الليلي، الصلاة القادمة بعدّ تنازلي، بطاقة «أكمل من حيث توقفت» مع حلقة الختمة وشريط ورد اليوم،
  بطاقة رمضان (قبله بعشرة أيام وفيه: عدّاد الإفطار والإمساك) أو الأذكار في وقتها، آية اليوم (صورة · نص · التفسير)، وأربع أدوات.
- **المصحف**: صفحة المصحف نفسها دون إنترنت (أسطر مصحف المدينة، الإطار، الضغط على الآية: تفسير ميسر، استماع، نسخ، مشاركة كصورة، علامات، بحث).
  حجم الخط من الإعدادات يكبّر خط المصحف.
- **ختمتي** (الختمة الذكية كاملة): حسب المدة أو الورد اليومي، البداية من الفاتحة أو من حيث توقفت، أيام الراحة، سياسة فوات يوم،
  الورد ينتهي عند نهاية الجزء، تُحتسب الصفحة بعد بقائك عليها ١٢ ثانية، هذا الأسبوع، متقدّم/متأخر، الختمات السابقة، والتهنئة عند الختم.
- **الاستماع**: صفحة القرّاء، وزر «⬇ تحميل للاستماع بدون إنترنت» تحت المشغّل، و«التلاوات المحمّلة» بمشغّل يعمل مع قفل الشاشة.
- **الأدوات**: سلسلة الأيام، الفهرس، ختمتي، المحمّلة، الترجمات، المواقيت، القبلة (بوصلة باتجاه ومسافة وتنبيه عند الاتجاه الصحيح)،
  الأذكار، المسبحة (٨ أذكار، ٣٣/٩٩/١٠٠/بلا حد، المجموع)، أذكار بعد الصلاة، آية لحالك (ومشاركتها صورة)، الإهداء/الصدقة الجارية (بطاقة باسم من تحب)،
  التنبيهات، الإعدادات.
- **التنبيهات**: الأذان مع فضل الصلاة والصلاة التالية وزرّي «أذكار بعد الصلاة» و«شارك الأجر»، الشروق وفضل الضحى، تذكير الصيام المسنون
  (الاثنين والخميس والبيض وعرفة وعاشوراء)، الإفطار في رمضان، آية اليوم بصورتها، الورد مع تقدّمك و«ذكّرني بعد ساعة» والتذكير الثاني اللطيف،
  أذكار الصباح والمساء (مرتبطة بالصلاة أو بوقت ثابت)، سورة الكهف كل جمعة، وأخبار صاحب التطبيق من `app-notice.json`.
- **الويدجت**: مواقيت الصلاة الذكي (المتبقي، شريط التقدّم، الصلوات الخمس، البطاقة الذكية: الضحى، ساعة الإجابة، الثلث الأخير…)،
  آية اليوم، ختمتي، رمضان — على الشاشة الرئيسية، ومواقيت الصلاة وآية اليوم وختمتي على شاشة القفل أيضًا.
- **أخرى**: الترحيب عند أول تشغيل، جولة المميزات بعد التحديث، اختصارات أيقونة التطبيق، إبقاء الشاشة مضاءة، المظهر (تلقائي/نهاري/ليلي)،
  طريقة حساب المواقيت تلقائيًا حسب الدولة أو يدويًا، توحيد ألوان الموقع وأرقامه داخل التطبيق (نفس bridge.js)، حجب الإعلانات، شاشة «لا يوجد اتصال».

## فروق يفرضها نظام iOS
- **الإشعارات المجدولة**: iOS يسمح بـ٦٤ تنبيهًا مجدولًا فقط، فيُجدول التطبيق الأيام القادمة (الأقرب فالأقرب) ويجددها كلما فُتح وفي التحديث الدوري في الخلفية.
  تظهر في الإعدادات تحت «تنبيه الأذان» حتى أي تاريخ هي مجدولة.
- **صوت الأذان**: صوت إشعارات الجوال (لا قنوات صوت كما في أندرويد). وإعدادات «دقة الأذان» والبطارية غير لازمة: تنبيهات iOS تصل في الدقيقة نفسها.
- **«المواقيت»** تفتح شاشة أصلية بالمواقيت الستة والصلاة القادمة (ومنها رابط لصفحة الموقع)، بدل صفحة الموقع مباشرة.
- **الأخبار الفورية (Firebase)** غير مفعّلة بعد في iOS؛ الأخبار تصل بالفحص الدوري لملف `app-notice.json` كما في أندرويد. الإرسال الفوري يحتاج إعداد APNs لاحقًا.
- **التحديث وتقرير الأعطال**: يتولاهما App Store وTestFlight، فلا زر «البحث عن تحديث».
- **اختصارات الأيقونة**: أربعة (حد iOS): آية لحالك، المصحف، الاستماع، القبلة.
- **فتح روابط الموقع في التطبيق مباشرة** (App Links): يحتاج ملف `apple-app-site-association` في الموقع — مرحلة لاحقة.

## الخطوات

### ١) افحص البناء الآن (مجانًا، قبل تفعيل الحساب)
1. ارفع المشروع إلى GitHub كما تفعل دائمًا.
2. من تبويب **Actions** افتح **«بناء تطبيق iOS»** (يعمل تلقائيًا عند تعديل `ios/`، أو اضغط **Run workflow**).
   - تعديل ملفات `ios/` وحدها **لا** يصدر نسخة أندرويد جديدة.
3. إن ظهرت ✅ في خطوة **build** فالتطبيق والويدجت يُبنيان بلا أخطاء.
   إن ظهرت ❌: نزّل **ios-build-log** من أسفل صفحة التشغيل وأرسله لي لأصلحه.
   (خطوة **testflight** ستُتخطّى برسالة «لم تُضف أسرار حساب Apple بعد» — هذا طبيعي.)

### ٢) بعد تفعيل Apple Developer
- خذ **Team ID** من developer.apple.com/account ← Membership details.

### ٣) المعرّفات ومجموعة التطبيق (App Group)
developer.apple.com/account ← Certificates, Identifiers & Profiles ← Identifiers:
1. ➕ **App Groups** ← المعرّف: `group.com.hawlalaalam.quran` (الوصف: Hawl).
2. ➕ **App IDs** ← App ← Bundle ID: `com.hawlalaalam.quran` ← فعّل **App Groups** واختر المجموعة أعلاه.
3. ➕ **App IDs** ← App ← Bundle ID: `com.hawlalaalam.quran.widgets` ← فعّل **App Groups** واختر المجموعة نفسها.
(الويدجت يقرأ المواقيت والختمة وآية اليوم من هذه المجموعة.)

### ٤) أنشئ التطبيق في App Store Connect
appstoreconnect.apple.com ← Apps ← ➕ New App:
- Platform: iOS · Name: حول العالم | القرآن الكريم · Primary language: Arabic
- Bundle ID: **com.hawlalaalam.quran** · SKU: hawlalaalam-quran

### ٥) أنشئ مفتاح API للرفع التلقائي
App Store Connect ← Users and Access ← **Integrations** ← App Store Connect API ← ➕:
- الاسم: GitHub · الصلاحية: **Admin** (أو App Manager)
- انسخ **Issuer ID** و**Key ID**، ونزّل ملف **AuthKey_XXXX.p8** (يُنزَّل مرة واحدة فقط، احفظه).

### ٦) أضف الأسرار في GitHub
المستودع ← Settings ← Secrets and variables ← Actions ← **New repository secret**:

| الاسم | القيمة |
|---|---|
| `APPLE_TEAM_ID` | Team ID من الخطوة ٢ |
| `ASC_KEY_ID` | Key ID |
| `ASC_ISSUER_ID` | Issuer ID |
| `ASC_KEY_P8` | افتح ملف .p8 بمحرر نصوص والصق محتواه كاملًا (مع سطري BEGIN وEND) |

ثم من Actions ← «بناء تطبيق iOS» ← **Run workflow**. بعد ١٥–٣٠ دقيقة تظهر النسخة في App Store Connect ← TestFlight.

### ٧) المختبرون عبر TestFlight
- **Internal Testing**: أضف نفسك (وأي حساب في فريقك) فتصلك النسخة فورًا دون مراجعة.
- **External Testing** ← ➕ مجموعة ← أضف النسخة ← املأ «What to Test» ومعلومات المراجعة ← Submit for Review (مراجعة سريعة لأول نسخة).
- بعد الموافقة فعّل **Public Link** وأرسله لأهلك وأصدقائك؛ يثبّتون تطبيق TestFlight ثم يفتحون الرابط.

### ٨) النشر في App Store
عند الرضا عن النسخة: App Store Connect ← التطبيق ← صفحة المتجر (الوصف، الصور، رابط الخصوصية، فئة Reference أو Books) ← اختر النسخة ← Submit for Review.
صور المتجر المطلوبة: آيفون ٦٫٩ إنش (1320×2868) — أجهّزها لك بعد أول نسخة ناجحة على TestFlight.

## كل نسخة جديدة
أي تعديل في `ios/` يُرفع إلى main يبني نسخة ويرفعها إلى TestFlight تلقائيًا (رقم البناء = رقم التشغيل في GitHub).
لتغيير رقم الإصدار الظاهر (1.0) عدّل `MARKETING_VERSION` في `ios/project.yml`.
