# تطبيق «حول العالم» على iOS

تطبيق آيفون/آيباد أصلي (SwiftUI) بنفس تصميم أندرويد الجديد، ويقرأ بيانات المصحف والخطوط من مجلد أندرويد نفسه
(`app/src/main/assets/quran` و`app/src/main/res/font`) فلا توجد نسختان تحتاجان مزامنة.
يُبنى بالكامل على GitHub — لا تحتاج جهاز ماك.

## ما الذي فيه
- **اليوم**: الترويسة بالتاريخ الهجري والمدينة، الصلاة القادمة بعدّ تنازلي، «أكمل القراءة» والفهرس، الأذكار في وقتها، آية اليوم (صورة · نص · التفسير)، وأربع أدوات.
- **المصحف**: صفحة المصحف نفسها دون إنترنت (أسطر مصحف المدينة، البحث، التفسير الميسر، الاستماع، المشاركة كصورة)، ويحفظ آخر صفحة وسلسلة الأيام.
- **الفهرس**: السور والأجزاء، والبحث بالاسم أو الرقم أو الصفحة (دون تشكيل أو همزات).
- **الاستماع**: صفحة القرّاء من الموقع، والتلاوة تستمر عند قفل الشاشة.
- **الأدوات**: سلسلة الأيام، المواقيت، القبلة بالبوصلة، المسبحة، الأذكار، أذكار بعد الصلاة، الأدعية، آية لحالك، الترجمات، الإعدادات، «اجعلها صدقة جارية».
- **التنبيهات**: الأذان لكل صلاة مع زر «أذكار بعد الصلاة»، آية اليوم بالوقت الذي تختاره، أذكار الصباح والمساء، سورة الكهف كل جمعة.

## لم تُنقل بعد (مرحلة لاحقة)
- خطة الختمة الذكية وحلقة التقدّم (يحفظ آخر صفحة فقط الآن).
- الويدجت على الشاشة الرئيسية (تحتاج WidgetKit).
- إشعارات «الأخبار» من صفحة الإدارة (تحتاج إعداد APNs في حساب Apple).
- تحميل التلاوات للاستماع دون إنترنت.
- تذكير الأذكار بأوقات ثابتة (٦:٣٠ ص و٥:٠٠ م) لا بحسب الصلاة.

## الخطوات

### ١) افحص البناء الآن (مجانًا، قبل الاشتراك)
1. ارفع المشروع إلى GitHub كما تفعل دائمًا.
2. من تبويب **Actions** افتح **«بناء تطبيق iOS»**.
   - تعديل ملفات `ios/` وحدها **لا** يصدر نسخة أندرويد جديدة.
3. إن ظهرت ✅ في خطوة **build** فالتطبيق يُبنى بلا أخطاء.
   إن ظهرت ❌: نزّل **ios-build-log** من أسفل صفحة التشغيل وأرسله لي لأصلحه.
   (خطوة **testflight** ستُتخطّى برسالة «لم تُضف أسرار حساب Apple بعد» — هذا طبيعي.)

### ٢) اشترك في Apple Developer
- من developer.apple.com/programs ‏(٩٩ دولارًا سنويًا).
- الجمعيات الخيرية المسجّلة قد تحصل على إعفاء من الرسوم: developer.apple.com/support/membership-fee-waiver
- بعد التفعيل خذ **Team ID** من developer.apple.com/account ← Membership details.

### ٣) أنشئ التطبيق في App Store Connect
appstoreconnect.apple.com ← Apps ← ➕ New App:
- Platform: iOS · Name: حول العالم | القرآن الكريم · Primary language: Arabic
- Bundle ID: **com.hawlalaalam.quran** (إن لم يظهر في القائمة: أنشئه من developer.apple.com ← Identifiers ← ➕ App IDs)
- SKU: hawlalaalam-quran

### ٤) أنشئ مفتاح API للرفع التلقائي
App Store Connect ← Users and Access ← **Integrations** ← App Store Connect API ← ➕:
- الاسم: GitHub · الصلاحية: **Admin** (أو App Manager)
- انسخ **Issuer ID** و**Key ID**، ونزّل ملف **AuthKey_XXXX.p8** (يُنزَّل مرة واحدة فقط، احفظه).

### ٥) أضف الأسرار في GitHub
المستودع ← Settings ← Secrets and variables ← Actions ← **New repository secret**:

| الاسم | القيمة |
|---|---|
| `APPLE_TEAM_ID` | Team ID من الخطوة ٢ |
| `ASC_KEY_ID` | Key ID |
| `ASC_ISSUER_ID` | Issuer ID |
| `ASC_KEY_P8` | افتح ملف .p8 بمحرر نصوص والصق محتواه كاملًا (مع سطري BEGIN وEND) |

ثم من Actions ← «بناء تطبيق iOS» ← **Run workflow**. بعد ١٥–٣٠ دقيقة تظهر النسخة في App Store Connect ← TestFlight.

### ٦) المختبرون عبر TestFlight
- في TestFlight أجب عن سؤال التشفير إن طُلب (التطبيق لا يستخدم تشفيرًا خاصًا، وقد صُرّح بذلك في الإعدادات).
- **External Testing** ← ➕ مجموعة ← أضف النسخة ← املأ «What to Test» ومعلومات المراجعة ← Submit for Review (مراجعة سريعة لأول نسخة).
- بعد الموافقة فعّل **Public Link** وأرسله لمختبريك؛ يثبّتون تطبيق TestFlight ثم يفتحون الرابط.

### ٧) النشر في App Store
عند الرضا عن النسخة: App Store Connect ← التطبيق ← صفحة المتجر (الوصف، الصور، رابط الخصوصية، فئة Reference أو Books) ← اختر النسخة ← Submit for Review.
صور المتجر المطلوبة: آيفون ٦٫٩ إنش (1320×2868) — أجهّزها لك بعد أول نسخة ناجحة على TestFlight.

## كل نسخة جديدة
أي تعديل في `ios/` يُرفع إلى main يبني نسخة ويرفعها إلى TestFlight تلقائيًا (رقم البناء = رقم التشغيل في GitHub).
لتغيير رقم الإصدار الظاهر (1.0) عدّل `MARKETING_VERSION` في `ios/project.yml`.
