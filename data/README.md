|---|---|---|
| tafsir-ibn_kathir / tabari / baghawi / qurtubi | المكتبة القرآنية الشاملة QUL ‏(qul.tarteel.ai) عبر مشروع Tafsir API | نصوص تراثية؛ مع نسبة المصدر |
| tr-en_hilali_khan, tr-ur_junagarhi, tr-tr_diyanet, tr-ru_kuliev | مشروع تنزيل tanzil.net/trans | للاستخدام غير التجاري مع ذكر المصدر ورابط tanzil.net/trans |
